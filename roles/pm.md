# Role Specification: Product Manager (PM)

## Overview
Defines user requirements, feature backlogs, and criteria for successful completion of project tasks.

## User Stories & Acceptance Criteria

### US-1: Assignment Ingestion
- **User Story:** As a student, I want to input my syllabus text so that the system extracts assignment deadlines automatically.
- **Acceptance Criteria:** 
  - System extracts subject name, task name, and due date.
  - Returns output within 3 seconds.

### US-2: Smart Task Sorting
- **User Story:** As a student, I want my dashboard sorted by priority so that I know what to work on first.
- **Acceptance Criteria:**
  - High-priority tasks appear at the top.
  - Tasks can be manually checked off upon completion.
