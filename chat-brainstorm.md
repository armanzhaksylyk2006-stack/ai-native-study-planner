# Brainstorming Session: Smart Student Workspace

**User:** I want to create a web application for SDU students that helps them track deadlines, assignments, and study schedules using AI. What are the core features?

**AI:** That's a practical idea! Here are the core specifications:
1. **Assignment Parser:** Automatically extracts due dates from syllabus texts or screenshots.
2. **AI Task Prioritizer:** Ranks tasks by urgency, weight, and effort.
3. **Interactive Student Dashboard:** Displays daily study targets.

**User:** How should we structure the project specification according to AI-native workflow?

**AI:** We need to set up the following files:
- `AGENT.md`: Defines the system prompt, constraints, and operational logic for the AI model.
- `process.md`: Outlines the application architecture and data flow.
- `roles/pm.md`: Contains Product Manager user stories and acceptance criteria.
